# MEGA — Discord RPG Bot

A World of Warcraft-inspired RPG bot for Discord. Create a character, gear up, fight mobs, run dungeons, and more — all from within your server. Responses are rendered as stylized images in the WoW aesthetic.

## Commands

All commands use the `ab` prefix (e.g. `ab hero`, `ab create`).

| Command | Description |
|---|---|
| `ab hero` | View your character sheet |
| `ab create` | Create a new character |
| `ab delete` | Delete your character |
| `ab inspect [user]` | Inspect your own or another player's equipment |
| `ab inventory` | List the items in your inventory |
| `ab full inventory` | Show full item details for everything in your inventory |
| `ab equip <item>` | Equip an item from your inventory |
| `ab unequip <item>` | Unequip a worn item |
| `ab use <item>` | Use a consumable or active item |
| `ab sell <item>` | Sell an item for gold |
| `ab item <name>` | Look up an item's stats |
| `ab shop <name>` | Browse and buy from a shop |
| `ab train` | Fight random mobs to earn experience and gold |
| `ab run <dungeon>` | Enter a dungeon |
| `ab gather <resource> <type>` | Gather crafting resources |
| `ab resources` | View your current resource stockpile |
| `ab craft <item>` | Craft an item from resources |
| `ab help` | Link to the full command reference |
| `ab report <message>` | Send feedback or report a bug |

## Character Creation

When you run `ab create` you'll choose:

- **Race** — Orc (+1 primary stat) or Human (+1 stamina)
- **Class** — Warrior (heavy armor), Mage (high damage), or Rogue (balanced)

## Dungeons

Currently available:
- **Deadmines** — `ab run deadmines` (requires attunement key from the Deadmines shop)

Bosses support a **Challenge Mode** for harder fights and better loot.
